## About

I'm a final-year **B.Tech Computer Engineering student at NMIMS MPSTME, Mumbai**, interested in building reliable software systems and infrastructure.

My main areas of interest are:

* Backend engineering and distributed systems
* Cloud infrastructure and DevOps
* Security and automation
* Applied machine learning

I enjoy working on systems where software meets infrastructure — from APIs and databases to deployment pipelines, cloud architecture, and security.
